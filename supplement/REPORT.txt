Implementation choices
The archive preserves original directory layout under payload/ so unchanged sources resolve their imports and relative reads. The runner verifies input hashes, copies the payload to a fresh retained working directory under runs/, compiles installed C++17 code with assertions enabled, runs the checks, and compares stable outcomes with the expected summary. It separately identifies the printed matching/table words with the regenerated terminal matrices. The immutable payload and manifest survive repeated runs.
The default recomputes complete finite terminal classifications and relevant FC catalogues, verifies the proved uniform/affine/E10 families and matching certificate, and verifies the supplied D6 recurrence certificate. Historical full E6/E7 group-enumeration snapshots are compared by default and freshly recomputed only with --full. Random searches, capped KL probes, exploratory discovery engines, prebuilt binaries, full generated FC snapshots, and unrelated material are excluded. The E9 and E10 discovery-result JSON inputs are reduced to the exact fixed seed rows consumed by the proof verifiers, with transformations and source hashes recorded. The D6 24,245-record dependency certificate is retained intact.
The affine and E10 arithmetic libraries contain their original optional entry points but those exploratory/unneeded entry points are not run. Source dependencies are expressly disclosed; no blanket claim of complete implementation independence is made.
The ZIP and all work remain under supplement/ to respect the assigned directory boundary. A parent may copy the finished ZIP to output/supplement/ without changing its bytes.
